# Rosangela Bolos

Sistema inventario virtual de produtos, estoque e vendas da empresa Rosangela Bolos, desenvolvido como projeto acadêmico.

## Funcionalidades

- Autenticação de usuários com login e senha
- Cadastro, consulta, alteração e exclusão de produtos
- Controle de quantidade disponível e estoque mínimo
- Busca de produtos por nome ou categoria
- Registro de vendas com cálculo automático do valor total
- Atualização automática do estoque após cada venda
- Histórico das últimas 20 vendas
- Gerenciamento de usuários

## Tecnologias utilizadas

- PHP
- MySQL
- HTML5
- CSS3
- PDO

## Banco de dados

MySQL — armazenamento de produtos, usuários e vendas.
